## 设置与结果口径

- 模型为本地 Qwen3.5-9B，BF16 / SDPA，16,384 总窗口，4,096 输出上限，temperature 0.6、top_p 1.0、top_k 50、thinking 关闭；沿用固定截断与重试规则。
- 300 条训练池：easy、medium、hard 各 100；150 条验证：各 50；1000 条项目测试来自官方 distractor dev。固定数据 seed 42，三组原始 ID 互斥，所有条件共用同一划分。
- 实验 seed 为 0、42、127。每种子比较无技能、初始技能、原方法，并加载选中技能进行同种子验证集重复评估。
- 原方法三轮、种群二、每轮两个新候选；每次训练反馈评估抽 15 题，最多三条失败反馈。300 是训练池规模，不是全量微调；模型权重不训练。
- 每条件上限 3000 次请求、1000 万输出 token；包含初始化、格式尝试、失败与重试。实际用量另外计量。

下表以每个种子的 `selected_val` 作为原方法成绩，全部使用相同的 150 条验证题。EM/F1 为百分比；均值和样本标准差按三个实验种子计算，不把三次评估视为 450 道独立题。

| Seed | 无技能 EM / F1 | 初始技能 EM / F1 | 进化选定技能 EM / F1 |

| 0 | 70.00 / 80.40 | 69.33 / 80.53 | 70.00 / 81.39 |
| 42 | 68.67 / 80.07 | 66.67 / 77.08 | 70.67 / 81.73 |
| 127 | 70.67 / 81.84 | 68.00 / 79.05 | 72.00 / 83.95 |

| 条件 | EM 均值 ± 样本标准差 | F1 均值 ± 样本标准差 |
|---|---:|---:|
| 无技能 | 69.78 ± 1.02 | 80.77 ± 0.94 |

相对初始技能，选定技能平均 EM **+2.89**、F1 **+3.47** 个百分点；相对无技能，平均 EM **+1.11**、F1 **+1.59** 个百分点。三个种子相对初始技能的 EM 都提升；相对无技能，seed 0 持平，42 和 127 分别净多答对 3 题、2 题。

初始技能在三个种子上的 EM 都低于无技能，均值低 1.78 个百分点。不能用“加入技能必然更好”解释本次结果；C 需要根据完整逐题输出核对其错误类型和变化原因。进化改善了当前初始化的表现，但相对无技能的收益仍较小。
